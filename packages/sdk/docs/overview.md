# sdk

Runtime-agnostic TypeScript SDK for the Lumen control plane API

A shared package of the lumen workspace, consumed by the components
below at build time.

## Depended on by

- **cli** — First-class TypeScript CLI for the Lumen control plane API
- **web-console-next** — Next.js 15 + opennextjs/cloudflare delivery of the Lumen web console (per-environment, Workers + Static Assets)
